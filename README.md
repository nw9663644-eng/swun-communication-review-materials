## 西南民族大学通信工程专业课程资料

本仓库用于整理和备份本科阶段课程资料。

希望这份资料能帮到后面的学弟学妹。也欢迎大家继续补充、修正和完善这个资料库。

如果你手里有新的复习资料、笔记、实验资料或更好的整理版本，可以通过下面的“如何投稿资料”提交。为了保证资料质量和避免侵权、隐私问题，投稿内容会先经过审核，再整理进仓库或网盘。

## 如何下载

推荐优先使用百度网盘下载，速度通常比 GitHub 更稳定：

- 百度网盘链接：https://pan.baidu.com/s/1uGQa_IZQhPVVyg4bTc0jGg?pwd=8888
- 提取码：8888

GitHub 备用下载方法：

因为资料大多是 `.zip` 压缩包，并且使用 Git LFS 存储，GitHub 网页可能无法直接预览文件内容。

单个文件下载方法：

1. 在文件列表中点击想下载的课程压缩包，例如 `复变.zip`。
2. 如果页面提示文件太大无法显示，点击页面中的 `View raw`。
3. 浏览器会自动开始下载该 `.zip` 文件。

如果想下载全部资料，可以在仓库首页点击绿色 `Code` 按钮，再选择 `Download ZIP`。如果这种方式没有包含完整的大文件，请改用上面的单个文件下载方法。

## 如何投稿资料

欢迎补充和完善资料，但请不要直接上传不确定来源的内容。

推荐投稿方式：

1. 点击仓库上方的 `Issues`。
2. 点击 `New issue`。
3. 选择“资料投稿”模板。
4. 按模板填写课程名、资料说明、网盘链接和来源说明。
5. 仓库维护者审核后再整理到仓库或百度网盘。

会使用 GitHub 的同学也可以通过 Fork 仓库后提交 Pull Request。具体方法见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 说明

- 压缩包文件使用 Git LFS 管理，适合存放较大的课程资料文件。
- GitHub 显示 `Stored with Git LFS` 是正常现象，表示大文件已经存储成功。
- 上传公开仓库前，请确认资料不包含个人隐私、考试原题、教师未授权课件、付费教材扫描版等不适合公开传播的内容。
- 如果资料来源不确定，建议先使用 GitHub 私有仓库。
